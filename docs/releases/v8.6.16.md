# v8.6.16

Released: 2026-09-09

## English

### Fixes and reliability

- CCB Mobile now uses the compact single-host view when only one paired host
  is reachable, dynamically aggregates multiple reachable hosts on refresh,
  and retains offline pairings for management. Initial connection can fall
  back to the sole reachable host without taking over an established session.
- Project registration replaces obsolete identities for the same normalized
  path and filters stale identities on load. Health checks reject a different
  project ID returned by the daemon; same-named projects at different paths
  remain distinct.
- Claude pane recovery restores API credentials after environment cleanup,
  correcting the export/unset ordering in #340. Persisted commands remain
  redacted. Claude transcript selection skips metadata preambles (#342).
- Codex recovery handles fork continuations while distinguishing real
  subcommands from option values such as a profile named fork (#341).
- tmux startup and empty-server keepalive configuration execute in one command
  queue, closing the remaining race in #343. Smoke-test failure reports now
  retain cleanup errors and residue evidence.
- Reverted #344: managed Claude homes do not point their default Keychain at
  the user's login database. One-way Provider inheritance and Windows/Herdr
  isolation remain core PR maintenance requirements.

### Upgrade and limitations

Upgrade both the CCB host and Mobile APK and restart the Mobile gateway.
No configuration or pairing migration is required. Discovering another host
requires a refresh; this release does not add background host polling.
Windows remains beta. Native macOS authentication qualification remains open;
this release preserves the existing Keychain boundary rather than claiming
that the managed-HOME login issue from #344 is resolved.

## 中文

### 修复与稳定性

- CCB Mobile 在只有一台已配对主机可达时显示简洁单机列表，刷新后可动态
  聚合多台在线主机，并保留离线配对供管理。首次连接可以回退到唯一可达主机，
  不会接管已经建立的会话。
- 同一规范化项目路径重新注册时替换过期身份，加载时过滤旧身份；健康检查
  拒绝 daemon 返回的不同项目 ID，不同路径的同名项目仍分别保留。
- Claude pane 恢复在环境清理后补入 API 凭据，修正 #340 的 export/unset
  顺序问题，持久化命令继续隐藏凭据。会话选择会跳过元数据前导记录（#342）。
- Codex 恢复支持 fork 延续，并区分真实子命令和名为 fork 等选项值，避免
  错误截断启动命令（#341）。
- tmux 启动和空服务器保活设置在同一个命令队列执行，关闭 #343 遗留的竞态。
  冒烟测试失败报告保留清理错误和残留证据。
- 回退 #344：managed Claude HOME 不将默认 Keychain 指向用户登录数据库。
  Provider 单向继承和 Windows/Herdr 隔离继续作为 PR 维护核心要求。

### 升级与限制

请同时升级 CCB 主机和 Mobile APK，并重启 Mobile gateway。无需迁移配置或
配对。发现另一台主机需要刷新，本版未新增后台主机轮询。Windows 仍为 beta。
真实 macOS 认证验证仍待完成；本版保留原有 Keychain 边界，不声称已经解决
#344 所描述的 managed HOME 登录问题。
